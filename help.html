Mafia Mod Installer

v0.16-beta

About

Mafia Mod Installer (MMI) is a Windows tool for managing mods of Mafia: The City of Lost Heaven (2002). It builds a per-instance clean backup, lets you install/uninstall mods in priority order, generates a custom intro logo, packs and shares .mmi bundles, and detects common issues via the built-in troubleshooter.

1. Quick start

  1. Launch MMI. If it can't find Mafia automatically, use File → Select game folder or Service → Instance Finder.
  2. You will be asked whether to make a clean backup now (OK) or later. The size is shown up-front. Without a clean backup MMI refuses to install mods, but you can defer the decision.
  3. Drop a mod ZIP/RAR/7z or a .mmi package on the program window, or use the Upload tab.
  4. Tick the mods you want active, then click Install.

2. The four tabs

Install

Pick an instance, tick mods and hit Install or Install & Run. The Auto-extract .dta checkbox extracts A0.dta… etc. before mod files are copied so the engine prefers your loose files. Off by default — turn it on when a mod needs game-level overrides.

Mod library

List of all imported mods. Right-click for: rename, change priority, change target game version, open mod folder, open readme, pack as .mmi, remove. Multi-select supported (Ctrl/Shift + click).

Upload

Drag-and-drop or browse for an archive. Optional: alias name, priority, target game version. Multi-root archives are split into separate library entries.

Saves

Auto-/manual snapshots of savegame/. Each backup remembers which mods were active at the time (column Mods at backup).

3. Service menu

  • Revert one / all instances — restore an instance from its clean backup.
  • Find duplicate mods — flags identical mods by SHA-256.
  • Troubleshooter — version checks, rw_data.dll status, suspicious installers, broken layouts. Save report… writes a detailed mmi_report_*.txt with file trees and checksums.
  • Instance Finder — scans the disk for Mafia folders by detecting LS3DF.dll + Game.exe. Modes: Auto (common locations), Full (all drives), Selective (one folder you pick). Never scans the MMI install folder.
  • Manage Instances — list, open path, check version, or Forget an instance from MMI (does not delete the game).
  • Cache sounds — extracts A0.dta and AB.dta as loose files. Useful for digital editions where music doesn't play due to expired licenses.

4. Settings reference

  • Insert logo — generate an intro logo listing installed mods.
  • Use alternative logo — use logo1_alt.avi with no overlay.
  • Widescreen — adjust logo for widescreen patch resolutions.
  • Auto-detect widescreen fix — toggle Widescreen on automatically if Mafia.WidescreenFix is detected (default ON).
  • Conflict check, Immutable saves, Auto-backup savegame — installation safety toggles.
  • Experimental autodetect target version — guesses the mod's target game version from its readme (off by default).
  • Recommended count — warn if you're trying to install more than N mods at once.

5. .mmi packages

Build with right-click → Create .mmi. A .mmi is a ZIP with manifest.json + one inner archive per mod. Use it to share several mods + priorities in a single file. MMI re-imports any .mmi by drag-and-drop.

6. FAQ

I get "no clean backup" when clicking Install.
You chose Later when MMI offered to make the clean backup. Click File → Make clean backup, or hit Install again to retry the dialog.
Music doesn't play on my Steam/GOG Mafia.
That's a known issue with digital re-releases (expired Take-Two music licenses). Run Service → Cache sounds; once music/* exists as loose files the engine plays the tracks. You also need rw_data.dll patched (Settings → Patch rw_data.dll).
A mod won't install / produces errors.
Run Service → Troubleshooter and save the report. Common causes: target version mismatch, rw_data.dll not patched, mod ships as a Windows installer (.exe) instead of loose files.
How do I add a new language?
Open the language dropdown → + Add language…. From there pick a translation *.json, or generate an AI prompt with the full en.json and paste it into ChatGPT/Claude.
Can I uninstall just one mod without reverting everything?
Yes — uncheck it and click Install again. MMI tracks per-file ownership and rolls back only the files that mod touched.

1. Быстрый старт

  1. Запустите MMI. Если папка с игрой не найдена автоматически — Файл → Выбрать папку игры или Сервис → Поиск экземпляров.
  2. Появится диалог: сделать чистый бэкап сейчас (OK) или позже. Размер показан заранее. Без чистого бэкапа моды не ставятся, но решение можно отложить.
  3. Перетащите ZIP/RAR/7z или .mmi в окно программы — или используйте вкладку Загрузка.
  4. Отметьте нужные моды и нажмите Установить.

2. Четыре вкладки

Установка

Выберите экземпляр, отметьте моды и нажмите Установить/Установить и запустить. Чекбокс Авто-распаковка .dta распаковывает A0.dta и т. п. до копирования файлов мода, чтобы движок предпочёл ваши loose-файлы. По умолчанию ВЫКЛ.

Библиотека модов

Список всех импортированных модов. Правый клик: переименовать, поменять приоритет, изменить целевую версию игры, открыть папку, открыть readme, упаковать как .mmi, удалить. Поддерживается множественный выбор.

Загрузка

Drag-and-drop или выбор архива. Опционально: алиас, приоритет, целевая версия игры. Мульти-корневые архивы автоматически разбиваются на отдельные записи библиотеки.

Сохранения

Авто и ручные снимки savegame/. Каждый бэкап помнит, какие моды были активны (колонка Моды при бэкапе).

3. Сервис

  • Откат экземпляров — восстановление из чистого бэкапа.
  • Поиск дубликатов — мод-дубликаты по SHA-256.
  • Средство устранения неполадок — проверки версии, rw_data.dll, подозрительных установщиков. Сохранить отчёт… пишет mmi_report_*.txt с tree файлов и контрольными суммами.
  • Поиск экземпляров — сканирует диск на наличие папок Mafia по LS3DF.dll + Game.exe. Режимы: Авто (типовые локации), Full (все диски), Выборочный (одна папка по выбору). Папка установки MMI никогда не сканируется.
  • Управление экземплярами — список, открыть путь, проверить версию, Забыть экземпляр (не удаляет игру).
  • Закэшировать sounds — распаковывает A0.dta и AB.dta в loose-файлы. Нужно для лицензионных изданий, где из-за истёкших лицензий не играет музыка.

4. Настройки

  • Вставлять логотип — генерация интро со списком модов.
  • Использовать альтернативный логотип — logo1_alt.avi без оверлея.
  • Widescreen — корректировка логотипа под широкоэкранный фикс.
  • Авто-определение WidescreenFix — автоматически включать widescreen при обнаружении (по умолчанию ВКЛ).
  • Проверка конфликтов, Иммутабельные сохранения, Авто-бэкап savegame — параметры безопасности.
  • Авто-определение целевой версии (экспериментально) — определение по readme.
  • Рекомендуемое число модов — предупреждение при превышении.

5. Пакеты .mmi

Правый клик → Создать .mmi. Это ZIP с manifest.json и одним вложенным архивом на мод. Удобно для отправки сразу нескольких модов с приоритетами. MMI принимает .mmi drag-and-drop.

6. FAQ

«Нет чистого бэкапа» при попытке установки.
Вы выбрали Позже в диалоге создания бэкапа. Файл → Сделать чистый бэкап или повторно нажмите «Установить».
Не играет музыка в Steam/GOG-версии.
Известная проблема цифровых изданий (истекли лицензии Take-Two). Запустите Сервис → Закэшировать sounds. Также может понадобиться патч rw_data.dll.
Мод не ставится / ошибки.
Запустите средство устранения неполадок и сохраните отчёт. Типичные причины: несоответствие версий, не пропатчен rw_data.dll, мод приходит как установщик .exe вместо loose-файлов.
Как добавить язык?
В выпадающем списке языков выберите + Add language…. Можно подобрать готовый *.json или сгенерировать AI-промпт со встроенным en.json.
Можно ли снять только один мод?
Да — снимите галку и нажмите «Установить». MMI ведёт учёт по файлам и откатит только те, что трогал этот мод.

1. Rychlý start

  1. Spusťte MMI. Pokud hru nenajde automaticky, použijte Soubor → Vybrat složku hry nebo Servis → Hledání instancí.
  2. Objeví se dialog: vytvořit čistou zálohu nyní (OK) nebo později. Velikost je vidět dopředu. Bez čisté zálohy MMI nedovolí instalovat mody.
  3. Přetáhněte ZIP/RAR/7z nebo .mmi do okna programu, nebo použijte záložku Nahrát.
  4. Zaškrtněte mody a klikněte na Instalovat.

2. Čtyři záložky

Instalace

Vyberte instanci, zaškrtněte mody a klikněte na Instalovat/Instalovat a spustit. Auto-rozbalení .dta rozbaluje A*.dta před zkopírováním souborů modu. Ve výchozím nastavení vypnuto.

Knihovna modů

Seznam importovaných modů. Pravé tlačítko: přejmenovat, změnit prioritu, změnit cílovou verzi hry, otevřít složku/readme, vytvořit .mmi, odebrat. Podporován vícenásobný výběr.

Nahrání

Drag-and-drop nebo procházení archivu. Volitelně: alias, priorita, cílová verze. Vícekořenové archivy se automaticky rozdělí.

Uložené pozice

Automatické a ruční zálohy savegame/. Každá záloha si pamatuje aktivní mody (sloupec Mody při záloze).

3. Servis

  • Obnova instancí — z čisté zálohy.
  • Najít duplicity — podle SHA-256.
  • Poradce při potížích — kontroly verze, rw_data.dll a další. Uložit zprávu… generuje mmi_report_*.txt.
  • Hledání instancí — skenuje disky na LS3DF.dll + Game.exe. Režimy: Auto, Full, Selektivní. Složka MMI se nikdy neskenuje.
  • Správa instancí — seznam, otevřít cestu, ověřit verzi, Zapomenout instanci (hru nemaže).
  • Cache sounds — rozbalí A0.dta a AB.dta do loose souborů (pomáhá s hudbou v digitálních edicích).

4. Nastavení

  • Vložit logo — generování intra se seznamem modů.
  • Použít alternativní logo — logo1_alt.avi bez překryvu.
  • Widescreen — úprava loga pro širokoúhlé rozlišení.
  • Automatická detekce Widescreen Fixu — zapne Widescreen, pokud najde fix (výchozí ZAP).
  • Kontrola konfliktů, Neměnné uložené pozice, Auto-záloha savegame.
  • Auto-detekce cílové verze (experimentální).
  • Doporučený počet modů — upozornění při překročení.

5. Balíčky .mmi

Pravým tlačítkem → Vytvořit .mmi. Je to ZIP s manifest.json a jedním vnořeným archivem na mod. Vhodné pro sdílení sady modů s prioritami. MMI přijímá .mmi drag-and-drop.

6. FAQ

„Není čistá záloha" při instalaci.
Klikli jste na Později v dialogu. Soubor → Vytvořit čistou zálohu nebo znovu klikněte Instalovat.
V mé Steam/GOG verzi nehraje hudba.
Známý problém digitálních edic (expirované licence Take-Two). Použijte Servis → Cache sounds. Možná bude potřeba i patch rw_data.dll.
Mod se neinstaluje nebo hází chyby.
Spusťte poradce při potížích a uložte zprávu.
Jak přidat jazyk?
V rozevíracím seznamu jazyků → + Add language…. Vyberte *.json nebo vygenerujte AI prompt s plným en.json.
Lze odinstalovat jen jeden mod?
Ano — zrušte zaškrtnutí a klikněte Instalovat. MMI vrátí zpět jen jeho soubory.
