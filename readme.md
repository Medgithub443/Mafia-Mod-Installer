# Mafia Mod Installer

Универсальный установщик модов для **Mafia: The City of Lost Heaven**

## Быстрый старт

Чтобы установить свой первый мод:

1. Откройте вкладку **"Загрузка мода"**.
2. Нажмите кнопку выбора и укажите скачанный архив с модом.
3. Введите название мода и нажмите **"Загрузить"**.
4. Мод появится в вашей библиотеке. Посмотреть все моды можно на вкладке **"Установленные моды"**.

## Как установить моды в игру

1. Перейдите на вкладку **"Установка"**.
2. Убедитесь, что выбрана папка с установленной игрой.
   - Если папка не выбрана, нажмите **"Добавить игру"** и укажите путь к игре (например, `C:\Program Files (x86)\Steam\steamapps\common\Mafia\Mafia`).
3. В правом нижнем блоке **"Менеджер модов"** отметьте галочками один или несколько модов, которые хотите установить.
4. Нажмите **"Установить в игру"**.
5. Чтобы сразу запустить игру, нажмите **"Установить и запустить"** или кнопку **"Запустить игру"** отдельно.

## Как вернуть игру в исходное состояние

1. Закройте игру, если она запущена.
2. На вкладке **"Установка"** в **"Менеджере модов"** снимите все галочки.
3. Нажмите **"Установить в игру"**. Игра будет возвращена к чистому состоянию.

## Возможности программы

- **Смена языка**: русский, английский, чешский (выпадающий список вверху).
- **Патч rw_data.dll**: установка исправления для поддержки модов.
- **Создание бэкапов**: возможность в любой момент сохранить текущее состояние игры.
- **Восстановление из бэкапа**: откат к ранее сохранённому состоянию.
- **Автоматический чистый бэкап**: для каждой добавленной игры автоматически создаётся резервная копия исходных файлов. Она всегда доступна для восстановления.
- **Очистка ресурсов**: удаление папок, созданных модами (tables, maps, models и т.д.).
- **Создание MMI-архивов**: можно собрать несколько модов в один файл `.mmi`, с которым работает программа.

## Системные требования

- Windows (программа поставляется в виде `.exe`)
- Установленная игра Mafia: The City of Lost Heaven
