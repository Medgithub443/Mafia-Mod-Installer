Mafia Mod Installer — Помощь

Основные понятия

  • Экземпляр игры — конкретная папка установки (Steam, GOG, пиратская копия). Можно держать несколько одновременно.
  • Чистая резервная копия (clean_backup) — снимок ванильной игры, делается автоматически при первом подключении папки.
  • auto_backup — кэш оригинальных файлов, к которым обращались моды. Используется для отката без чтения всего clean_backup.
  • Библиотека модов — глобальная (общая для всех экземпляров). Один раз загрузил — используешь везде.
  • Менеджер модов — на странице «Установка», справа. Отметьте моды и нажмите «Установить в игру».

Загрузка модов

  • Поддерживаются ZIP / 7z / RAR / .mmi архивы и обычные папки.
  • На странице «Загрузка мода» введите название и выберите архив или папку.
  • Перетаскивание (Drag & Drop) тоже работает.
  • После загрузки мод появляется на вкладке «Установленные моды».

Приоритет модов

Целое число ≥ 1. Меньшее значение = устанавливается раньше, более крупное число — устанавливается позже и переписывает то, что лежит ниже.

  • Например: City Bars Mod (приоритет 2) — базовый, City Bars Mod+ (приоритет 3) — дополнение поверх.
  • По умолчанию для новых модов = 2.
  • Изменить можно в библиотеке модов (правый клик → «Изменить приоритет»).

Сборка .mmi-пакета

  • На вкладке «Установленные моды» — кнопка «Создать .mmi файл».
  • Можно отметить нужные моды, либо нажать «Выбрать всё».
  • Опционально вписать текст MMI_readme — увидит человек, который импортирует пакет.
  • Пакет сохраняется без сжатия — быстро и без зависимости от архиватора.

Логотип игры

Перед запуском игры программа подменяет logo1.avi на сгенерированный — со списком установленных модов. Сборка идёт через ffmpeg_avi_mp3.exe.

Если установлен Widescreen Fix — включите в настройках «Совместимость с Widescreen Fix для логотипа», иначе логотип будет растянут.

Сервис

  • Вернуть все экземпляры в исходное состояние — копирует clean_backup поверх каждой папки игры. Двойное подтверждение.
  • Поиск дубликатов модов — по контрольным суммам (SHA-256). Помогает найти случайно загруженный мод дважды.

Возможные проблемы

Игра не запускается после установки модов.
Зайдите в Настройки → «Пропатчить rw_data.dll» и выберите проблемный экземпляр.
MafiaCon не подключается.
Используйте правый клик по кнопке «Запустить игру» → «Запустить MafiaCon.exe». Программа учтёт рабочую директорию.
